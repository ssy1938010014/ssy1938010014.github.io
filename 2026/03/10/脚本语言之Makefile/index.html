本节主要介绍makefile相关的基本概念。

Makefile基础

  • Makefile由若干条规则（Rule）构成，每一条规则指出一个目标文件（Target），若干依赖文件（prerequisites），以及生成目标文件的命令。

  • makefile默认执行第一条规则，上述代码中make == make all

  • makefile的核心逻辑是：默认把目标名当成“要生成的文件名”

    • 所以当执行 make clean 时，它会先看当前目录里有没有一个叫 clean 的文件：

      • 有 clean 文件，且它看起来不需要更新（常见是 clean 没依赖）→ make 认为目标已完成，不跑命令。

      • 没有 clean 文件 → 才会执行 clean: 下的 rm -f ...。
